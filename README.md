The practice repository for **BTE Build Session: Navigating GitHub**. This is where you apply everything from Sections 01–03 for real — fork it, clone it, open a pull request against it.

## What this is

This isn't a real product. It's a safe, disposable repo built specifically so beginners can go through a real fork → clone → branch → commit → push → PR cycle without breaking anything that matters.

## Quickstart

```bash
# 1. Fork this repo on GitHub first (top-right "Fork" button)
# 2. Clone YOUR fork, not this one
git clone https://github.com/YOUR-USERNAME/bte-navigating-github.git
cd bte-navigating-github

# 3. Link back to the original so you can stay in sync
git remote add upstream https://github.com/btetotheworld/bte-navigating-github.git
```

Full walkthrough: see [`docs/03-contributing-with-github.md`](docs/03-contributing-with-github.md).
