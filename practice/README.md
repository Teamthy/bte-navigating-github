# Practice Drills

Four hands-on exercises, one per Git/GitHub skill. Do them in order — each builds on the last.

| Drill | Skill | Section |
| --- | --- | --- |
| [`01-first-commit`](drills/01-first-commit) | `git add`, `git commit` | Section 01 |
| [`02-branching`](drills/02-branching) | `git checkout -b`, branch switching | Section 01 |
| [`03-merge-conflict`](drills/03-merge-conflict) | Causing and resolving a real conflict | Section 01 |
| [`04-open-a-pr`](drills/04-open-a-pr) | Fork, clone, PR against this repo | Section 03 |
| [`05-staging-and-unstaging`](drills/05-staging-and-unstaging) | `git add`, `git restore --staged` | Section 01 |
| [`06-undo-a-commit`](drills/06-undo-a-commit) | `git reset --soft HEAD^` | Section 01 |
| [`07-reading-a-real-repo`](drills/07-reading-a-real-repo) | Reading CONTRIBUTING.md, activity, labels on a real repo | Section 02 |
| [`08-finding-good-first-issues`](drills/08-finding-good-first-issues) | GitHub search, `label:"good first issue"` | Section 02 |
| [`09-syncing-your-fork`](drills/09-syncing-your-fork) | `git pull upstream main`, cleaning up branches | Section 03 |
| [`10-writing-a-pr-description`](drills/10-writing-a-pr-description) | Writing a PR description that gets reviewed | Section 03 |

Each drill folder has its own `README.md` with the exact task. Do these on your **own fork** — don't push drill work to this repo directly.
