# Drill 04: Open a Real Pull Request

This is the one that leaves this repo. Full steps are in `docs/03-contributing-with-github.md` — this drill is the checklist version.

Designed for the whole session to do **at the same time**: your PR only touches your own file, so you don't need to wait for anyone else, and it auto-merges without a human reviewer.

## Task

1. Fork this repository.
2. Clone your fork and add `upstream` pointing back here.
3. Create a branch: `git checkout -b add-me-to-participants`
4. Copy `practice/participants/TEMPLATE.md` to `practice/participants/<your-github-username>.md` and fill it in.
5. Commit, push to `origin`, and open a pull request against this repo's `main`.
6. Watch it auto-merge within a minute or two — see `practice/participants/README.md` for why that's safe here.

## Check yourself

Your file shows up in `practice/participants/` on this repo's `main` branch after merge, and you never had to wait on a reviewer.
