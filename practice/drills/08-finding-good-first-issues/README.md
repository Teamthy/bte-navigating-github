# Drill 08: Finding Good First Issues

Applies Section 02, Topic 6. No git commands — this is a search drill.

## Task

1. Go to `github.com/topics/good-first-issue`.
2. Pick 3 different repositories (not this one).
3. For each, open the Issues tab and filter: `label:"good first issue" state:open`
4. In `findings.md`, list one open beginner issue per repo — title, link, and one sentence on what it would involve fixing.

## Why this matters

This is the actual skill you'll use after this course ends — finding your next real contribution once you're done here.
