# Drill 07: Reading a Real Repo (no commands, no code)

Applies Section 02. Pick any well-known public repository (e.g. `facebook/react`, `microsoft/vscode`, or one from `github.com/topics/good-first-issue`) and answer the questions in `answers.md`.

## Task

Open the repo on GitHub and find:

1. Does it have a `CONTRIBUTING.md`? Link it.
2. What's the most recent commit date? Is the project active?
3. Find one issue labeled `good first issue` or `help wanted`. Link it.
4. What branch does the repo default to?
5. Does it have a `CODE_OF_CONDUCT.md`?

Write your answers in `answers.md`.
