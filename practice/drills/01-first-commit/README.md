# Drill 01: Your First Commit

## Task

1. Open `notes.txt` in this folder.
2. Add one line with your name and today's date.
3. Run `git status` — confirm the file shows as modified.
4. Stage it: `git add practice/drills/01-first-commit/notes.txt`
5. Commit it: `git commit -m "Add my first commit"`

## Check yourself

Run `git log --oneline -1` — your commit message should be the last thing on top.
